# M3.5 — Performance & Automation

## Features Delivered

### 1. NVENC GPU Hardware Acceleration
**File**: `app/services/gpu_encoder.py`
- `detect_nvenc()` → `EncoderInfo` dataclass (has_nvenc, gpu_name, encoder_name)
- Checks nvidia-smi for GPU presence, then ffmpeg -encoders for h264_nvenc support
- `get_encode_args()` returns NVENC args with libx264 fallback
- NVENC args: `-hwaccel cuda -hwaccel_output_format cuda -c:v h264_nvenc -preset fast -rc vbr -cq 23`
- Fallback args: `-c:v libx264 -preset fast -crf 23 -pix_fmt yuv420p`

### 2. Auto Lip-Sync Speech-Rate Adjuster
**File**: `app/workflow/audio_dubbing_service.py` — updated `tts_segments()` method
- `_find_ffprobe()` helper for ffprobe discovery (same fallback chain as _find_ffmpeg)
- `_calculate_speech_rate(original_duration, tts_path)` → Edge-TTS rate string
- 3-stage pipeline per segment:
  1. Generate TTS at normal speed, convert to WAV
  2. Measure TTS duration vs original; if ratio outside 0.85–1.15, regenerate with adjusted rate
  3. Final fallback: FFmpeg `atempo` filter if still off by >5%
- Rate clamped to ±15% (Edge-TTS safe range)
- Atempo clamped to [0.5, 2.0] (FFmpeg valid range)

## Key Implementation Notes

### SceneMotion iteration pattern
`TrackedObject.motion` is `SceneMotion | None`. To iterate frames:
```python
if not source.motion:
    raise HTTPException(400, "Object has no motion data")
for m in source.motion.frames:  # NOT source.motion directly
    if m.centroid_x > 0:
        source_motion = m
        break
```

### Auto-match character logic
Cross-scene matching uses positional and size similarity:
- Position: `abs(m.centroid_x - source_motion.centroid_x) < 200`
- Size: `abs(m.bbox.width - source_motion.bbox.width) < 100`
- Skips same scene, skips objects without motion data
- Copies `replacement_config` from source to matched objects
