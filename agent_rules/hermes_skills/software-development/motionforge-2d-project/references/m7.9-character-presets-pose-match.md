## AI pose heuristic (`auto_pose_for_bbox`)
```python
if width <= 0 or height <= 0: return "talking"
if width > height * 1.1:  return "sitting"    # wide → lying/sitting
if height > width * 1.3:  return "standing"   # tall → standing/walking
return "talking"                               # balanced
```
- Test gotcha: `(220, 200)` is NOT wide (220 > 200*1.1 is False — 220 == 220). Use `(250, 200)` for a wide assertion.

## Session gotchas (generalizable)
- **read_file truncation**: `read_file` truncates long lines with `...[truncated]`; round-tripping via read_file → write_file in a script loses that content. Use Python `open().read()` in the script for transforms.
- **Bulk string-replace editing of Python**: after replacing many long lines, verify with `python -c "import ast; ast.parse(open(f).read())"` — an IndentationError revealed a mangled file mid-session (a script had deleted a trailing chunk).
- **Recover mangled file**: `git checkout HEAD -- <file>` then re-apply changes in smaller patches with unique context.
- **Ruff E501**: `ruff check --fix` does NOT fix line-too-long; manually break cv2/ellipse/rectangle calls across lines (already covered in SKILL.md).
- **`oid2` F821**: capture the second object's `object_id` into a variable (`obj2.json()["object_id"]`) instead of referencing the response object by a wrong name.
